# 34. LLM-Security-Range — Κυβερνοπεδίο Επίθεσης και Άμυνας σε Εφαρμογές LLM
### A Gamified Attack–Defense Range for LLM Application Security (Prompt Injection and Guardrails)

## Στοιχεία Έργου
- **Πηγαίος φάκελος:** `gamified-llm-security-platform/`
- **Θεματική περιοχή:** Ασφάλεια μεγάλων γλωσσικών μοντέλων, prompt injection, μηχανισμοί Guardrails, εκπαιδευτικά κυβερνοπεδία
- **Τεχνολογίες:** Next.js, TypeScript, προσομοιωτές σεναρίων, γλώσσα κανόνων Guardrails, προαιρετική δοκιμή σε τοπικό/ιδιόκτητο μοντέλο
- **Ενδεικτικός αριθμός φοιτητών:** 1–2

## Εκφώνηση Διπλωματικής Εργασίας

Αντικείμενο της εργασίας είναι η σχεδίαση, υλοποίηση και αξιολόγηση εκπαιδευτικού κυβερνοπεδίου στο οποίο ο εκπαιδευόμενος πρώτα παραβιάζει μια **προσομοιωμένη** εφαρμογή με LLM (prompt injection, jailbreak, δηλητηρίαση RAG, κατάχρηση εργαλείων) σε ασφαλές εργαστήριο και κατόπιν γράφει κανόνες Guardrails που σταματούν τις ίδιες παραλλαγές χωρίς να αποκλείουν νόμιμους χρήστες. Ο φοιτητής καλείται να μελετήσει ταξινομήσεις απειλών (π.χ. OWASP LLM Top 10, MITRE ATLAS) και τις δημοσιευμένες τεχνικές άμυνας, και να αντιστοιχίσει κάθε αποστολή σε συγκεκριμένο μαθησιακό στόχο.

Ζητείται πλατφόρμα με κλιμακωτές αποστολές, διαβαθμισμένες υποδείξεις που δεν αποκαλύπτουν αμέσως τη λύση, αυτόματη βαθμολόγηση επίθεσης (σύλληψη σημαίας στην προσομοίωση) και άμυνας (σουίτα περιπτώσεων επίθεσης και καλοήθων εισόδων). Η γλώσσα κανόνων των Guardrails πρέπει να είναι περιορισμένη και ασφαλής (κανονικοποίηση, φραγή εισόδου/εξόδου, απόκρυψη, άρνηση εργαλείων), με έλεγχο για επικίνδυνες κανονικές εκφράσεις (ReDoS). Προαιρετική δοκιμή σε πραγματικό μοντέλο επιτρέπεται **μόνο** έναντι μοντέλου που ελέγχει ο ίδιος ο φοιτητής (τοπικό ή προσωπικό κλειδί API), ποτέ έναντι υπηρεσιών τρίτων χωρίς εξουσιοδότηση. Δεν παράγονται οδηγίες επίθεσης σε πραγματικά συστήματα εκτός του κλειστού εργαστηρίου.

Η εργασία περιλαμβάνει τεκμηρίωση σεναρίων, μετρικές ισορροπίας ασφάλειας–χρηστικότητας των Guardrails και συζήτηση ορίων (κανόνες έναντι στατιστικών αμυνών, παράκαμψη με κωδικοποιήσεις, ψευδώς θετικά). Τέλος, απαιτείται αξιολόγηση μάθησης και ανθεκτικότητας των κανόνων σε παραλλαγές που δεν ήταν στη σουίτα εκπαίδευσης.

## Αξιολόγηση και σημαντικά αποτελέσματα

**Πώς διεξάγεται.** Αυτοματοποιημένη σουίτα: ποσοστό επιτυχούς παραβίασης προσομοίωσης, ποσοστό αποκλεισμού επιθέσεων μετά την επιδιόρθωση, ποσοστό αποδοχής καλοήθων εισόδων, αριθμός υποδείξεων και προσπάθειες μέχρι το πρώτο επιτυχές Guardrail. Πιλοτική χρήση εκπαιδευομένων με προ/μετα-έλεγχο εννοιών (όχι απομνημόνευση των σημαιών). Δοκιμή γενίκευσης σε νέες παραλλαγές επίθεσης. Έλεγχος ότι η γλώσσα κανόνων απορρίπτει επικίνδυνες κανονικές εκφράσεις.

**Αποτελέσματα που μετράνε.** Καμπύλη ασφάλειας–χρηστικότητας ανά αποστολή, μαθησιακό κέρδος χωρίς αποκάλυψη λύσης, αποτυχίες γενίκευσης των Guardrails και τεκμηρίωση ότι η δοκιμή σε πραγματικό μοντέλο παραμένει εντός εξουσιοδοτημένου μοντέλου.
