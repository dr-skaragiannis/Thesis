# 20. PhishGame — Παιχνίδι Ευαισθητοποίησης κατά του Phishing
### PhishGame: A Serious Game for Phishing Awareness and User Behaviour Evaluation

## Στοιχεία Έργου
- **Πηγαίοι φάκελοι:** `PhishGame - Website/`, `The-PhishGame/`
- **Θεματική περιοχή:** Ασφάλεια χρηστών, ευαισθητοποίηση, παιχνίδια σοβαρού σκοπού, κοινωνική μηχανική
- **Τεχνολογίες:** Web application, σενάρια/email προσομοίωσης, scoring, αναλυτικά στοιχεία
- **Ενδεικτικός αριθμός φοιτητών:** 1–2

## Εκφώνηση Διπλωματικής Εργασίας

Αντικείμενο της εργασίας είναι ο σχεδιασμός, η ανάπτυξη και η αξιολόγηση ενός παιχνιδιού ευαισθητοποίησης για επιθέσεις ηλεκτρονικού «ψαρέματος» (phishing). Ο φοιτητής καλείται να μελετήσει τις τεχνικές κοινωνικής μηχανικής, τους παράγοντες που οδηγούν τους χρήστες σε λάθη και τις υπάρχουσες προσεγγίσεις εκπαίδευσης, ώστε να σχεδιάσει σενάρια που προσομοιώνουν ρεαλιστικές αλλά ασφαλείς καταστάσεις.

Ζητείται η υλοποίηση διαδικτυακής εφαρμογής που παρουσιάζει σενάρια (π.χ. μηνύματα, ιστοσελίδες) και αξιολογεί την απόφαση του χρήστη, παρέχοντας άμεση, εκπαιδευτική ανατροφοδότηση και επεξήγηση των ενδείξεων. Ιδιαίτερη προσοχή απαιτείται στην ποιότητα των σεναρίων, στην ασφάλεια (κανένα πραγματικό απόρρητο δεδομένο), στην αποφυγή εκπαίδευσης σε επιβλαβείς τεχνικές και στην ευχρηστία.

Η εργασία πρέπει να περιλαμβάνει συστηματική αξιολόγηση: μέτρηση της βελτίωσης της αναγνώρισης phishing πριν/μετά, μελέτη συμπεριφοράς με χρήστες και στατιστική ανάλυση. Ο φοιτητής καλείται να ορίσει μετρικές, να συγκρίνει με εναλλακτικές προσεγγίσεις και να τεκμηριώσει τα αποτελέσματα.

Τέλος, απαιτείται συζήτηση δεοντολογικών ζητημάτων (συγκατάθεση, μη στοχοποίηση, προστασία δεδομένων) και προτάσεων επέκτασης, όπως προσαρμοστική δυσκολία, ομαδική εκπαίδευση και ενσωμάτωση σε προγράμματα ασφάλειας οργανισμών.

## Αξιολόγηση και σημαντικά αποτελέσματα

**Πώς διεξάγεται.** Μελέτη χρηστών με προ/μετα-έλεγχο αναγνώρισης phishing σε νέα σενάρια (όχι τα ίδια του παιχνιδιού). Καταγραφή αποφάσεων, χρόνου και επίδρασης της ανατροφοδότησης. Συγκατάθεση, ανωνυμοποίηση.

**Αποτελέσματα που μετράνε.** Ποσοστιαία βελτίωση διάκρισης, κατηγορίες λαθών (βιασύνη, αποστολέας, URL) και σύγκριση με στατικό ενημερωτικό υλικό.
