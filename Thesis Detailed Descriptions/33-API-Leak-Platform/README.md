# 33. API-Leak-Platform — Παιχνιδοποιημένη Πλατφόρμα Εκπαίδευσης σε Διαρροές API και Μυστικών
### A Gamified Training Platform for API Secret Leak Detection, Validation and Remediation

## Στοιχεία Έργου
- **Πηγαίος φάκελος:** `gamified-api-leak-detection-platform/`
- **Θεματική περιοχή:** Ασφάλεια εφαρμογών, διαχείριση μυστικών, DevSecOps, παιχνιδοποιημένη εκπαίδευση
- **Τεχνολογίες:** Next.js, React, TypeScript, PostgreSQL/Drizzle, ταξινομία περιστατικών, ρόλοι ανιχνευτή / επαληθευτή / διορθωτή, βαθμολόγηση
- **Ενδεικτικός αριθμός φοιτητών:** 1–2

## Εκφώνηση Διπλωματικής Εργασίας

Οι διαρροές μυστικών σε δημόσια αποθετήρια αποτελούν ώριμο εκπαιδευτικό πρόβλημα, υπό τον όρο ότι η πλατφόρμα διδάσκει αναγνώριση και αποκατάσταση και όχι «κυνήγι» ζωντανών κλειδιών. Η εργασία σχεδιάζει, υλοποιεί και αξιολογεί εκπαιδευτική πλατφόρμα για API keys, διακριτικά συνεδρίας, SAS/OAuth και εσφαλμένες ρυθμίσεις αποθήκευσης, μέσα από παιχνιδοποιημένες υποθέσεις και ταξινομία επιπέδων (αυθεντικοποίηση, IAM, υποδομή, ορατότητα δικτύου, πνευματική ιδιοκτησία, δεδομένα προσωπικού χαρακτήρα).

Η διαδικτυακή εφαρμογή φιλοξενεί καταγεγραμμένες **εκπαιδευτικές** υποθέσεις —βασισμένες σε δημοσίως γνωστά μοτίβα ή πλήρως συνθετικά σενάρια— στις οποίες ο εκπαιδευόμενος αναλαμβάνει ρόλους ανίχνευσης (scout), επαλήθευσης (validator) και διόρθωσης (fixer). Κάθε υπόθεση περιλαμβάνει τι πήγε στραβά, οδηγίες αποκατάστασης και κριτήρια βαθμολόγησης (τεκμήριο, σοβαρότητα, πρόταση επιδιόρθωσης). **Απαγορεύεται** η σάρωση ζωντανών αποθετηρίων τρίτων, η αναζήτηση πραγματικών κλειδιών και η αναπαραγωγή ενεργών διαπιστευτηρίων, το σύστημα εκπαιδεύει σε αναγνώριση και ορθή απόκριση, όχι σε «κυνήγι διαρροών» στο διαδίκτυο.

Η ταξινομία συνδέεται με μαθησιακούς στόχους. Οι ροές υποβολής, ψηφοφορίας και επιβραβεύσεων δεν επιβραβεύουν επιβλαβή συμπεριφορά. Η αξιολόγηση εξετάζει κατά πόσον οι εκπαιδευόμενοι μεταφέρουν τη γνώση σε νέα, άγνωστα σενάρια —hardcoded secret έναντι υπερβολικών δικαιωμάτων έναντι δημόσιου κάδου.

Υπεύθυνη αποκάλυψη, ΓΚΠΔ και τα όρια μεταξύ εκπαίδευσης και επιχειρησιακού bug bounty ολοκληρώνουν τη συζήτηση.

## Αξιολόγηση και σημαντικά αποτελέσματα

**Πώς διεξάγεται.** Πιλοτική χρήση με προκαθορισμένο σύνολο υποθέσεων. Μετρώνται χρόνος, ορθότητα ρόλου (ανακάλυψη / ψήφος / επιδιόρθωση), ακρίβεια ταξινόμησης επιπέδου και σοβαρότητας, και ποιότητα πρότασης αποκατάστασης έναντι ρουμπρίκας. Προ/μετα-έλεγχος σε **νέες** συνθετικές υποθέσεις. Ελέγχεται ότι δεν υπάρχουν πραγματικά μυστικά στο αποθετήριο σπόρου.

**Αποτελέσματα που μετράνε.** Βελτίωση ταξινόμησης και αποκατάστασης εκτός των υποθέσεων εξάσκησης, πίνακας σύγχυσης ανά επίπεδο ταξινομίας, αξιοπιστία του μηχανισμού βαθμών (όχι επιβράβευση τυχαίων ψήφων) και τεκμηρίωση δεοντολογικών ορίων της πλατφόρμας.
