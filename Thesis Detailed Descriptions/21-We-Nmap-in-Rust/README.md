# 21. We-Nmap-in-Rust (WNR) — Επαναϋλοποίηση Σαρωτή Δικτύου και Κονσόλα Ελέγχου
### We-Nmap-in-Rust (WNR): A Memory-Safe Network Scanner and Control-Room Dashboard for Exposure Assessment

## Στοιχεία Έργου
- **Πηγαίοι φάκελοι:** `We-Nmap-in-Rust/`, `We-Nmap-in-Rust - Copy/`, `wnr-nmap-dashboard/` (περιλαμβάνει `llm-prompt.md`)
- **Θεματική περιοχή:** Ασφάλεια δικτύων, σάρωση θυρών, μηχανική λογισμικού συστημάτων, οπτικοποίηση
- **Τεχνολογίες:** Rust (async/Tokio, πακέτα δικτύου), React/TypeScript dashboard, Nmap-συμβατή έξοδος (XML)
- **Ενδεικτικός αριθμός φοιτητών:** 1–2

## Εκφώνηση Διπλωματικής Εργασίας

Αντικείμενο της εργασίας είναι ο σχεδιασμός, η υλοποίηση και η αξιολόγηση ενός σαρωτή δικτύου υλοποιημένου σε Rust, ο οποίος προσομοιώνει ή επεκτείνει λειτουργικότητα εργαλείων όπως το Nmap, μαζί με μια κονσόλα ελέγχου για την οπτικοποίηση της έκθεσης ενός δικτύου. Ο φοιτητής καλείται να μελετήσει τις τεχνικές σάρωσης (αναγνώριση, σάρωση θυρών, ανίχνευση υπηρεσιών/λειτουργικού) και τις προκλήσεις απόδοσης και ασφάλειας στην ανάλυση δικτυακής κίνησης.

Ζητείται η υλοποίηση μηχανισμού σάρωσης με ασύγχρονη εκτέλεση, καθώς και διαδικτυακής κονσόλας που παρουσιάζει ευρήματα, διαφορές σαρώσεων και ενδείξεις κινδύνου. Ιδιαίτερη προσοχή απαιτείται στην ασφάλεια μνήμης και στη διαχείριση σφαλμάτων (που αποτελούν βασικό πλεονέκτημα της Rust), στην απόδοση, στη συμβατότητα εξόδου με πρότυπα και στη χρήση μόνο σε εξουσιοδοτημένα περιβάλλοντα.

Η εργασία πρέπει να περιλαμβάνει συστηματική πειραματική αξιολόγηση: σύγκριση ταχύτητας/ακρίβειας με εργαλεία αναφοράς, ανάλυση κατανάλωσης πόρων, έλεγχο ορθότητας και μελέτη ευχρησίας της κονσόλας. Ο φοιτητής καλείται να τεκμηριώσει τη μεθοδολογία, να ορίσει μετρικές και να συζητήσει τα όρια της προσέγγισης.

Τέλος, απαιτείται συζήτηση νομικών και δεοντολογικών ζητημάτων (εξουσιοδότηση, μη στοχοποίηση τρίτων), καθώς και προτάσεις επέκτασης, όπως υποστήριξη περισσότερων πρωτοκόλλων, ανίχνευση τρωτοτήτων και ενσωμάτωση με πληροφορίες απειλών.

## Αξιολόγηση και σημαντικά αποτελέσματα

**Πώς διεξάγεται.** Συγκριτικές σαρώσεις σε εξουσιοδοτημένο εργαστηριακό δίκτυο έναντι Nmap (ή αντίστοιχου): χρόνος, κάλυψη θυρών/υπηρεσιών, χρήση CPU/μνήμης, ορθότητα εξόδου XML. Αξιολόγηση ευχρηστίας κονσόλας (διαφορές σαρώσεων).

**Αποτελέσματα που μετράνε.** Πίνακες ταχύτητας/ακρίβειας, αποκλίσεις από το εργαλείο αναφοράς και τεκμηρίωση ότι δεν έγιναν σαρώσεις σε δίκτυα χωρίς άδεια.
