# 21. We-Nmap-in-Rust (WNR) — Βιβλιοθήκες σάρωσης δικτύου σε Rust και κονσόλα έκθεσης
### We-Nmap-in-Rust (WNR): Memory-Safe Rewrites of Nmap Core Libraries and an Exposure Dashboard

## Στοιχεία Έργου
- **Πηγαίοι φάκελοι:** `We-Nmap-in-Rust/` (βιβλιοθήκες `wnr-pcap`, `wnr-dnet`, `wnr-nsock`), `wnr-nmap-dashboard/` (ξεχωριστή κονσόλα)
- **Θεματική περιοχή:** Ασφάλεια δικτύων, μηχανική λογισμικού συστημάτων, ασφάλεια μνήμης, οπτικοποίηση έκθεσης
- **Τεχνολογίες:** Rust (επανυλοποίηση libpcap/Npcap, libdnet, Nsock χωρίς C FFI στον πυρήνα), Tokio, προαιρετικά React/TypeScript dashboard
- **Ενδεικτικός αριθμός φοιτητών:** 1–2

## Εκφώνηση Διπλωματικής Εργασίας

Η σάρωση δικτύου για εκτίμηση έκθεσης είναι εργαλείο ρουτίνας, αλλά η επανυλοποίηση των βιβλιοθηκών της σε γλώσσα με ασφάλεια μνήμης αλλάζει το προφίλ αξιοπιστίας. Η εργασία δεν ξεκινά από έναν ολοκληρωμένο σαρωτή ισοδύναμο του Nmap: επαναγράφει από το μηδέν, χωρίς C FFI στον πυρήνα, τις βιβλιοθήκες `wnr-pcap` (σύλληψη πακέτων), `wnr-dnet` (χαμηλού επιπέδου δικτύωση) και `wnr-nsock` (ασύγχρονα sockets), με συμπεριφορική αναφορά τις αντίστοιχες C υλοποιήσεις. Πάνω σε αυτές τις στρώσεις μπορεί να χτιστεί σταδιακά ανακάλυψη κόμβων και σάρωση θυρών. Ξεχωριστή διαδικτυακή κονσόλα (`wnr-nmap-dashboard/`) οπτικοποιεί ευρήματα, χωρίς να προϋποτίθεται ήδη πλήρης συμβατότητα εξόδου XML.

Η ασφάλεια μνήμης, τα τεστ ισοδυναμίας συμπεριφοράς με το upstream, η απόδοση και η χρήση **μόνο** σε εξουσιοδοτημένα εργαστήρια είναι μη διαπραγματεύσιμα. Η κονσόλα παρουσιάζει ό,τι πραγματικά παράγει ο σαρωτής στο στάδιο που έχει φτάσει η εργασία, όχι φανταστική πλήρη ισοδυναμία με το Nmap.

Η πειραματική αξιολόγηση συγκρίνει τις βιβλιοθήκες (και, όπου υπάρχει, τη σάρωση) με εργαλεία αναφοράς ως προς ορθότητα, πόρους και, εφόσον ωριμάσει, ταχύτητα/κάλυψη. Καταγράφονται μεθοδολογία, όρια και νομικά ζητήματα εξουσιοδότησης. Δεν γίνονται σαρώσεις σε δίκτυα χωρίς άδεια.

## Αξιολόγηση και σημαντικά αποτελέσματα

**Πώς διεξάγεται.** Συγκριτικές σαρώσεις σε εξουσιοδοτημένο εργαστηριακό δίκτυο έναντι Nmap ή αντίστοιχου εργαλείου: χρόνος, κάλυψη θυρών και υπηρεσιών, χρήση CPU/μνήμης, ορθότητα εξόδου XML. Αξιολογείται και η ευχρηστία της κονσόλας, ιδίως ως προς τις διαφορές σαρώσεων.

**Αποτελέσματα που μετράνε.** Πίνακες ταχύτητας και ακρίβειας, αποκλίσεις από το εργαλείο αναφοράς και τεκμηρίωση ότι δεν έγιναν σαρώσεις σε δίκτυα χωρίς άδεια.
