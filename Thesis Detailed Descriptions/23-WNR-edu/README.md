# 23. WNR-edu — Εκπαιδευτικό Cyber Range εξ ολοκλήρου στον Φυλλομετρητή
### WNR-edu: A Browser-Native Cyber Range with Diagnostic Lab Validation and Educator Analytics

## Στοιχεία Έργου
- **Πηγαίος φάκελος:** `wnr-edu/`
- **Θεματική περιοχή:** Εκπαιδευτική τεχνολογία, κυβερνοασφάλεια, εξομοίωση συστημάτων, αναλυτική μάθησης
- **Τεχνολογίες:** Next.js, React, TypeScript, xterm.js, Zustand, PostgreSQL/Drizzle, εικονικό σύστημα αρχείων και διερμηνέας εντολών στον πελάτη
- **Ενδεικτικός αριθμός φοιτητών:** 1–2

## Εκφώνηση Διπλωματικής Εργασίας

Αντικείμενο της εργασίας είναι η σχεδίαση, υλοποίηση και αξιολόγηση εκπαιδευτικού κυβερνοπεδίου που εκτελείται εξ ολοκλήρου στον περιηγητή ιστού, χωρίς εικονικές μηχανές ή απομακρυσμένους πράκτορες. Ο φοιτητής καλείται να μελετήσει πώς μπορεί ένα εικονικό σύστημα αρχείων και ένας διερμηνέας εντολών να αναπαραστήσουν αρκετά πιστά Linux, δικτυακή αναγνώριση, κρυπτογραφία, Active Directory και εγκληματολογία, ώστε να υποστηρίξουν πραγματική εξάσκηση και αυτόματο έλεγχο στόχων.

Ζητείται πλατφόρμα με ρόλους εκπαιδευόμενου και εκπαιδευτή, εργαστήρια ανά θεματικό τομέα, θεωρητικό υλικό, οικονομία υποδείξεων, σήματα/πρόοδο και τηλεμετρία. Κάθε εργαστήριο πρέπει να διαθέτει διαγνωστικούς ελέγχους που επιθεωρούν κατάσταση συστήματος αρχείων, δικαιώματα, αντικείμενα καταλόγου και ιστορικό εντολών, και να εξηγούν γιατί απέτυχε ένας έλεγχος. Ιδιαίτερη προσοχή απαιτείται στην ασφάλεια λογαριασμών, στην προστασία δεδομένων προόδου και στη διαφορά ανάμεσα σε εκπαιδευτική εξομοίωση και πραγματικό περιβάλλον.

Η εργασία πρέπει να περιλαμβάνει συστηματική αξιολόγηση: κάλυψη προγράμματος σπουδών, ορθότητα αυτόματης βαθμολόγησης, δοκιμές διαδρομών λύσης, ευχρηστία σε διαφορετικές συσκευές και, ιδανικά, μελέτη με τμήμα φοιτητών. Ο φοιτητής καλείται να μετρήσει πιστότητα εντολών, ψευδώς θετικά/αρνητικά στους ελέγχους και το μαθησιακό όφελος έναντι εργαστηρίων με πραγματικά VMs.

Τέλος, απαιτείται συζήτηση κλιμάκωσης και κόστους (μηδενική υποδομή κυβερνοπεδίου ανά φοιτητή), δεοντολογίας και προτάσεων επέκτασης, όπως επίμονη αποθήκευση κατάστασης εξομοιωτή, περισσότερα πρωτόκολλα και ενσωμάτωση ιδρυματικής ταυτοποίησης.

## Αξιολόγηση και σημαντικά αποτελέσματα

**Πώς διεξάγεται.** Αυτοματοποιημένες δοκιμές λύσεων εργαστηρίων (ορθές εντολές vs παγίδες), έλεγχος ψευδούς βαθμολόγησης, πιλοτική χρήση φοιτητών και μέτρηση πιστότητας εντολών έναντι πραγματικού Linux/AD όπου είναι εφικτό.

**Αποτελέσματα που μετράνε.** Ποσοστό εργαστηρίων με αξιόπιστο ελεγκτή λύσης, μαθησιακή πρόοδος, και χάρτης εντολών/συμπεριφορών που η εξομοίωση δεν αναπαριστά πλήρως.
