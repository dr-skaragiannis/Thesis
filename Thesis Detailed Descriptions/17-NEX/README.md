# 17. NEX — Πλατφόρμα Πληροφοριών Έκθεσης στον Κυβερνοχώρο
### NEX: A Cyber Exposure Intelligence Dashboard Integrating OSINT Providers and Risk Estimation

## Στοιχεία Έργου
- **Πηγαίοι φάκελοι:** `NEX/`, `deploy-nex-repository/` (ενσωματωμένη ανάπτυξη Next.js + PostgreSQL + FastAPI backend + paper)
- **Θεματική περιοχή:** Ασφάλεια δικτύων, OSINT, διαχείριση έκθεσης, εκτίμηση κινδύνου, μηχανική μάθηση
- **Τεχνολογίες:** Next.js, PostgreSQL, Drizzle, OSINT APIs (Shodan/ZoomEye/FOFA), ML εκτίμηση κινδύνου
- **Ενδεικτικός αριθμός φοιτητών:** 1–2

## Εκφώνηση Διπλωματικής Εργασίας

Αντικείμενο της εργασίας είναι η σχεδίαση, υλοποίηση και αξιολόγηση μιας πλατφόρμας πληροφοριών έκθεσης στον κυβερνοχώρο (cyber exposure intelligence) που συγκεντρώνει δεδομένα από ανοικτές πηγές (OSINT) και τα συνθέτει σε εύληπτη εικόνα κινδύνου για έναν οργανισμό. Ο φοιτητής καλείται να μελετήσει τις πηγές έκθεσης (υπηρεσίες σε ανοιχτά δίκτυα, εκτεθειμένα συστήματα), τις μεθόδους συλλογής και εμπλουτισμού δεδομένων και τις προκλήσεις αξιοπιστίας τους.

Ζητείται η υλοποίηση πλήρους στοίβας εφαρμογής με βάση δεδομένων, που ενσωματώνει δεδομένα από πολλαπλούς παρόχους, συσχετίζει ευρήματα με γνωστές ευπάθειες, παρακολουθεί ιστορικό σαρώσεων και εκτιμά τον κίνδυνο. Ιδιαίτερη προσοχή απαιτείται στη μετατροπή φυσικής γλώσσας σε δομημένα ερωτήματα, στη διαχείριση διαπιστευτηρίων παρόχων, στην απόδοση και στην ορθή διαχείριση των δεδομένων.

Η εργασία πρέπει να περιλαμβάνει μεθοδολογική αξιολόγηση: έλεγχο ορθότητας των συσχετίσεων, αξιολόγηση του μοντέλου εκτίμησης κινδύνου (π.χ. ακρίβεια, βαθμονόμηση), μετρήσεις απόδοσης και μελέτη ευχρησίας. Ο φοιτητής καλείται να συζητήσει τα ψευδώς θετικά, την αβεβαιότητα και τους περιορισμούς των δεδομένων OSINT.

Τέλος, απαιτείται συζήτηση νομικών και δεοντολογικών ζητημάτων (νόμιμη συλλογή, GDPR, υπεύθυνη αποκάλυψη), καθώς και προτάσεις επέκτασης, όπως αυτοματοποιημένη παρακολούθηση, ειδοποιήσεις και ενσωμάτωση με συστήματα διαχείρισης ευπαθειών.

## Αξιολόγηση και σημαντικά αποτελέσματα

**Πώς διεξάγεται.** Σύγκριση συσχετίσεων OSINT με γνωστά εργαστηριακά ευρήματα (όχι σάρωση τρίτων χωρίς εξουσιοδότηση). Αξιολόγηση βαθμονόμησης μοντέλου κινδύνου, χρόνων απόκρισης παρόχων και ευχρηστίας πίνακα. Καταγραφή ψευδώς θετικών.

**Αποτελέσματα που μετράνε.** Ακρίβεια εμπλουτισμού, σταθερότητα βαθμολογίας κινδύνου, κάλυψη παρόχων και νομική/δεοντολογική οριοθέτηση συλλογής.
