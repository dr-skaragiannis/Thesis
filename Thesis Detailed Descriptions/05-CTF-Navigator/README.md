# 5. CTF-Navigator — Ευφυής Καθοδηγητής για Ασκήσεις Capture the Flag
### CTF-Navigator: An AI-Assisted Learning Navigator for Capture-the-Flag Cybersecurity Exercises

## Στοιχεία Έργου
- **Πηγαίος φάκελος:** `CTF-NAVIGATOR-MAIN/` (και `CTF-NAVIGATOR-MAIN.zip`)
- **Θεματική περιοχή:** Εκπαιδευτική τεχνολογία, κυβερνοασφάλεια, ευφυείς διδακτικοί βοηθοί, LLM
- **Τεχνολογίες:** Firebase (Auth/Firestore), τοπικό ή απομακρυσμένο LLM (Ollama), frontend εφαρμογή
- **Ενδεικτικός αριθμός φοιτητών:** 1–2

## Εκφώνηση Διπλωματικής Εργασίας

Αντικείμενο της εργασίας είναι η σχεδίαση, ανάπτυξη και αξιολόγηση ενός ευφυούς καθοδηγητή που υποστηρίζει εκπαιδευόμενους κατά την επίλυση ασκήσεων τύπου Capture the Flag (CTF). Ο φοιτητής καλείται να μελετήσει πώς οι αρχάριοι προσεγγίζουν προβλήματα κυβερνοασφάλειας, ποια σημεία αποτελούν τροχοπέδη (π.χ. επιλογή εργαλείου, έλλειψη στρατηγικής, άγνοια αναγνώρισης) και πώς ένας βοηθός βασισμένος σε μεγάλα γλωσσικά μοντέλα μπορεί να παρέχει διαβαθμισμένη καθοδήγηση χωρίς να αποκαλύπτει τη λύση.

Ζητείται η υλοποίηση εφαρμογής που οργανώνει τις ασκήσεις, παρακολουθεί την πρόοδο του χρήστη και παρέχει στοχευμένες υποδείξεις και επεξηγήσεις. Η αρχιτεκτονική πρέπει να συνδυάζει ασφαλή διαχείριση χρήστη και δεδομένων προόδου (π.χ. Firebase) με μηχανισμό παραγωγής απαντήσεων από τοπικό ή απομακρυσμένο μοντέλο (π.χ. Ollama), και να ορίζει σαφείς πολιτικές για το τι μπορεί να αποκαλύψει ο βοηθός.

Η εργασία πρέπει να αντιμετωπίζει τεχνικές προκλήσεις, όπως ο έλεγχος των αιτημάτων προς το μοντέλο (prompt engineering, περιορισμός διαρροής λύσεων), η ανθεκτικότητα σε «παραπλάνηση» του βοηθού ώστε να δώσει την απάντηση, και η αξιολόγηση της ποιότητας των παρεχόμενων υποδείξεων. Απαιτείται συστηματική αξιολόγηση με μετρικές μάθησης (π.χ. χρόνος επίλυσης, ποσοστό επιτυχίας, αριθμός υποδείξεων), ιδανικά με ομάδα ελέγχου.

Τέλος, ο φοιτητής καλείται να τεκμηριώσει την αρχιτεκτονική, να συζητήσει ζητήματα ασφάλειας, ιδιωτικότητας και κόστους, και να προτείνει επεκτάσεις, όπως προσαρμογή της δυσκολίας στο επίπεδο του χρήστη, πολυγλωσσική υποστήριξη και ενσωμάτωση σε πλατφόρμες CTF.

## Αξιολόγηση και σημαντικά αποτελέσματα

**Πώς διεξάγεται.** Ομάδα με βοηθό έναντι ομάδας χωρίς (ή με στατικές υποδείξεις). Μετρώνται χρόνος επίλυσης, ποσοστό επιτυχίας, αριθμός υποδείξεων και αν ο βοηθός αποκάλυψε τη λύση σε δοκιμές «παραπλάνησης». Αξιολογείται ποιοτικά η χρησιμότητα των υποδείξεων.

**Αποτελέσματα που μετράνε.** Μαθησιακό όφελος χωρίς διαρροή λύσης, ανθεκτικότητα σε jailbreak/prompt injection του βοηθού, και κόστος/καθυστέρηση κλήσεων μοντέλου.
