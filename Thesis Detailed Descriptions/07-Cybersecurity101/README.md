# 7. Cybersecurity101 — Εκπαιδευτική Σουίτα Εργαστηρίων Δοκιμών Διείσδυσης
### Cybersecurity101: An Open, Bilingual (EL/EN) Hands-on Laboratory Suite for Teaching Offensive Security

## Στοιχεία Έργου
- **Πηγαίοι φάκελοι:** `Cybersecurity101/`, `Attack-Scripts/`
- **Θεματική περιοχή:** Ασφάλεια συστημάτων, εκπαίδευση κυβερνοασφάλειας, εργαστηριακές ασκήσεις, δοκιμές διείσδυσης
- **Τεχνολογίες:** Linux, δίκτυα, εργαλεία ασφάλειας, σενάρια/scripts, τεκμηρίωση Markdown
- **Ενδεικτικός αριθμός φοιτητών:** 1–2

## Εκφώνηση Διπλωματικής Εργασίας

Η διδασκαλία της κυβερνοασφάλειας μένει ατελής όταν οι φοιτητές διαβάζουν για επιθέσεις χωρίς να τις εξασκήσουν σε ασφαλές εργαστήριο. Η εργασία συγκροτεί μια ολοκληρωμένη εκπαιδευτική σουίτα, από βασικές έως προχωρημένες έννοιες. Μελετώνται υπάρχουσες προσεγγίσεις, προσδιορίζονται μαθησιακοί στόχοι και οι ασκήσεις οργανώνονται σε βαθμίδες δυσκολίας — από αναγνώριση και σάρωση δικτύου έως εκμετάλλευση και μετριασμό.

Το υλικό είναι δομημένο (οδηγοί βήμα προς βήμα, σενάρια, αυτοματοποιημένα scripts, περιβάλλοντα εξάσκησης) και δίγλωσσο, ελληνικά και αγγλικά, με σαφείς στόχους, προαπαιτούμενες γνώσεις και κριτήρια ολοκλήρωσης. Έμφαση δίνεται σε ασφαλές και απομονωμένο περιβάλλον, ώστε οι ασκήσεις να εκτελούνται νόμιμα και χωρίς κίνδυνο για πραγματικά συστήματα.

Χρειάζεται παιδαγωγική τεκμηρίωση και συστηματική αξιολόγηση: μαθησιακά αποτελέσματα, μέθοδοι ελέγχου της κατανόησης και συλλογή ανατροφοδότησης. Μετριέται η αποτελεσματικότητα των εργαστηρίων και η προσέγγιση συγκρίνεται με τη βιβλιογραφία.

Η αρχιτεκτονική των εργαστηρίων τεκμηριώνεται μαζί με οδηγίες αναπαραγωγής και πολιτική δεοντολογικής και νόμιμης χρήσης. Προτείνονται επεκτάσεις, όπως προσθήκη θεμάτων (cloud, κινητές συσκευές, ICS) και ενσωμάτωση αυτοματοποιημένης βαθμολόγησης.

## Αξιολόγηση και σημαντικά αποτελέσματα

**Πώς διεξάγεται.** Τα εργαστήρια δοκιμάζονται πιλοτικά με φοιτητές: χρόνος ολοκλήρωσης, ποσοστό επιτυχίας ανά άσκηση, πληρότητα του δίγλωσσου υλικού, λειτουργία σε απομονωμένο lab. Όπου είναι εφικτό, γίνεται προ/μετα-έλεγχος γνώσης.

**Αποτελέσματα που μετράνε.** Κάλυψη μαθησιακών στόχων ανά βαθμίδα, σημεία όπου οι εκπαιδευόμενοι κολλάνε, και επιβεβαίωση ότι οι ασκήσεις δεν εξαρτώνται από μη εξουσιοδοτημένους στόχους.
