# 7. Cybersecurity101 — Εκπαιδευτική Σουίτα Εργαστηρίων Δοκιμών Διείσδυσης
### Cybersecurity101: An Open, Bilingual (EL/EN) Hands-on Laboratory Suite for Teaching Offensive Security

## Στοιχεία Έργου
- **Πηγαίοι φάκελοι:** `Cybersecurity101/`, `Attack-Scripts/`
- **Θεματική περιοχή:** Ασφάλεια συστημάτων, εκπαίδευση κυβερνοασφάλειας, εργαστηριακές ασκήσεις, δοκιμές διείσδυσης
- **Τεχνολογίες:** Linux, δίκτυα, εργαλεία ασφάλειας, σενάρια/scripts, τεκμηρίωση Markdown
- **Ενδεικτικός αριθμός φοιτητών:** 1–2

## Εκφώνηση Διπλωματικής Εργασίας

Αντικείμενο της εργασίας είναι η σχεδίαση, ανάπτυξη και αξιολόγηση μιας ολοκληρωμένης εκπαιδευτικής σουίτας εργαστηρίων για τη διδασκαλία βασικών και προχωρημένων εννοιών κυβερνοασφάλειας. Ο φοιτητής καλείται να μελετήσει υπάρχουσες προσεγγίσεις στην εκπαίδευση ασφάλειας, να προσδιορίσει μαθησιακούς στόχους και να οργανώσει τις ασκήσεις σε βαθμίδες δυσκολίας, από αναγνώριση και σάρωση δικτύου έως εκμετάλλευση και μετριασμό.

Ζητείται η ανάπτυξη δομημένου υλικού (οδηγοί βήμα-προς-βήμα, σενάρια, αυτοματοποιημένα scripts, περιβάλλοντα εξάσκησης) σε δύο γλώσσες, ελληνικά και αγγλικά, με σαφείς στόχους, προαπαιτούμενες γνώσεις και κριτήρια ολοκλήρωσης. Ιδιαίτερη έμφαση δίνεται στη δημιουργία ασφαλούς και απομονωμένου περιβάλλοντος, ώστε οι ασκήσεις να εκτελούνται νόμιμα και χωρίς κίνδυνο για πραγματικά συστήματα.

Η εργασία πρέπει να περιλαμβάνει παιδαγωγική τεκμηρίωση και συστηματική αξιολόγηση: προσδιορισμό μαθησιακών αποτελεσμάτων, μεθόδους αξιολόγησης της κατανόησης των φοιτητών και συλλογή ανατροφοδότησης. Ο φοιτητής καλείται να μετρήσει την αποτελεσματικότητα των εργαστηρίων και να συγκρίνει την προσέγγισή του με τη βιβλιογραφία.

Τέλος, απαιτείται τεκμηρίωση της αρχιτεκτονικής των εργαστηρίων, οδηγίες αναπαραγωγής, πολιτική δεοντολογικής και νόμιμης χρήσης, καθώς και προτάσεις επέκτασης, όπως προσθήκη θεμάτων (cloud, κινητές συσκευές, ICS) και ενσωμάτωση αυτοματοποιημένης βαθμολόγησης.

## Αξιολόγηση και σημαντικά αποτελέσματα

**Πώς διεξάγεται.** Πιλοτική διεξαγωγή εργαστηρίων με φοιτητές: χρόνος ολοκλήρωσης, ποσοστό επιτυχίας ανά άσκηση, πληρότητα δίγλωσσου υλικού, λειτουργικότητα σε απομονωμένο lab. Προ/μετα-έλεγχος γνώσης όπου είναι εφικτό.

**Αποτελέσματα που μετράνε.** Κάλυψη μαθησιακών στόχων ανά βαθμίδα, σημεία όπου οι εκπαιδευόμενοι κολλάνε, και επιβεβαίωση ότι οι ασκήσεις δεν εξαρτώνται από μη εξουσιοδοτημένους στόχους.
